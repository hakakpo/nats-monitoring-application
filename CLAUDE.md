this application goal is to connect to nats application through monitoring port and get all the metrics needed and show them in good format, list, diagrams, stucked messages, stuck streams etc, consumers, speed of consuming etc... all the important metric to know what is going inside subjects, jetstream, application health etc... application is in java 21, spring boot 3.5 avec maven. the frontend is based on thymleaf with modern approaches. add alerting function in which we can add email address so that we can send when something is not working properly in nats or too much messages stuck etc. The application will be deployed on kubernetes using argocd. the helm part should in the project and the application will be available outside the cluster through ingress or kubernetes api gateway. value to be override by env, address to nats service running inside the same namespace and the ingress value to target the application
